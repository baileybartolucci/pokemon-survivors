法律信息、隐私与制作名单

非官方粉丝游戏

Pokémon Survivors 是由 Pedro Barretto 制作、由粉丝为粉丝打造的非官方粉丝游戏。游戏免费游玩；可选购的宝石只贩售外观道具，用来支付服务器与开发费用。

本游戏与 Nintendo、The Pokémon Company、GAME FREAK inc.、Creatures Inc. 或 Spike Chunsoft 无关，也未经其背书、赞助或核准。

Pokémon 及宝可梦角色名称是 Nintendo 的商标。Pokémon © Nintendo、Creatures Inc. 与 GAME FREAK inc.。其他所有商标皆属于其各自的拥有者。

免费、无广告

游戏是免费的，也会一直免费：没有广告，任何会影响对局或排行榜的东西都不用花钱。唯一能购买的是可选的宝石，用来换造型（见上方）。

宝可梦币（₽）只存在于游戏中，无法用真实金钱购买。

如果你愿意，可以在「赞助本项目」页面捐款。捐款是自愿的，而且只有在有账号时才会带来外观类的谢礼（称号、卡片外框、徽章、自选的异色宝可梦、一只同伴），不会改变对局或排行榜。

宝石

宝石是游戏的虚拟物品：只能购买外观道具（例如帽子、拖尾、称号和秘密基地的家具），会出现在对局、合作模式、竞技场和 Poké Realm 中，绝不会影响对战或排行榜。宝石没有现金价值，不能兑换成金钱，也不能转移到其他账号，只绑定在你的游戏账号上。

你可以透过游玩（每天第一场 5 分钟以上的对局、同一周玩满五天，以及竞技场，每日有上限）、在 Patreon 上赞助或购买宝石包来获得宝石。每个账号每天最多购买 R$ 300 的宝石包，未满 18 岁的玩家需取得父母或监护人的同意才能购买。宝石包以巴西雷亚尔计价，透过 Stripe（信用卡、Pix、Apple Pay、Google Pay 等）付款，在巴西以外会以你的币别显示金额，付款数据直接交给他们：游戏永远看不到你的卡片。

退货权：购买宝石包后 7 天内，你可以申请退还该宝石包中尚未使用的宝石（巴西消费者保护法第 49 条）。请附上购买编号，寄信至 pedro@wavyia.com.br 申请。已使用的宝石以及用宝石购买的外观道具不予退款。

付款被撤销或争议（chargeback）时，会从账号中扣除该宝石包的宝石，包括已使用的部分。余额可能变成负数，在余额为负时无法用宝石购买任何东西。

隐私

默认以访客身分游玩，不需要注册：游戏没有 Cookie 或广告，也从不要求你的姓名或电子邮件等个人数据。

游戏记住的一切都存在你浏览器的 localStorage 中，也就是你的设备上。以访客身分游玩时，这些数据都不会传送到任何服务器，只有 ph_ps 中的随机 ID 例外，它会随使用统计一起传送（见上方）：

ps:save
宝可梦币、在 Kecleon商店购买的强化、游戏内的宝可梦图鉴（看过的种类、击败的数量与收服了哪些）、孵化器中的蛋（eggs）、孵化的宝可梦（hatched）、任务进度、成就、纪录（例如击败的宝可梦数量与最长存活时间），以及你选择的称号。
ps:settings
设置：音乐与音效音量、声音开关、伤害数字与画面震动。
ps:lang
你的语言（繁体中文、英文、葡萄牙文、西班牙文或法文）。
ps:muted
只在你玩过旧版本时存在：设置功能推出前的静音标记。游戏只会读取，不再写入。
ps:account
只在你登录时存在：这台设备上登录的是哪个账号（账号 ID、你的名称与用户名），以及最后一次同步的进度版本。
ps:runs
只在有账号时存在：尚未送达排行榜的对局结果（例如脱机时）。服务器收到后就会删除。
ph_ps
这台设备的随机 ID，PostHog 用它来计算对局次数与错误（见上方）。它不会透露你是谁。

账号是选用的，会把你的进度保存在云端，让你可以在其他设备上继续玩。登录使用 Google，由 Clerk（clerk.com）处理，Clerk 会从 Google 取得你的名称、电子邮件与大头贴，并使用自己的 Cookie 让你保持登录。游戏永远看不到你的密码。

有账号时，ps:save 的副本会保存在我们的服务器上，与你的账号 ID 绑定。它会在你登录时、打开游戏时与每场对局结束时传送。我们的服务器会保存账号 ID、你的进度、创建与最后使用的时间，以及排行榜所需的数据（见上方），但不会保存你的电子邮件。

有账号时，每场对局也会进入排行榜：宝可梦、难度、存活时间、等级、击败的敌人数、是否获胜与游戏版本，以及对局开始与结束的时间，并与你的账号 ID 绑定。访客的对局永远不会进入排行榜。对局的重播（其种子与你的输入，不含个人数据）会一并传送，服务器可能会重新播放以验证结果。验证完成后，或服务器决定不验证该场对局时，重播就会被删除。

你的个人文件是公开的。登录时，你会选择一个显示名称与一个独一无二的用户名，后者会出现在个人文件的链接中。任何人，不论有没有账号，都能在排行榜与你的个人文件上看到：这两个名称、你装备的称号、各难度的纪录、宝可梦图鉴进度、最近的对局，以及追踪你和你追踪的人数。你的电子邮件与大头贴永远不会显示。你追踪了谁、谁追踪了你会保存在服务器上；个人文件只会显示人数。

退出登录后，你的进度仍会保留在这台设备上。若要删除你的账号、个人文件、排行榜对局与账号中保存的进度，请透过下方的联系方式提出。

若要删除这些数据，请在浏览器设置中清除网站数据。

图像、声音与字体都由本站提供，不会调用第三方服务。本站架设在 Cloudflare 上，和所有网页服务器一样，Cloudflare 可能会记录技术性的访问数据（例如 IP 地址），以运作并保护服务。

游戏中我们使用 PostHog（posthog.com，数据保存在美国）来了解游戏的游玩方式并修正错误。它会收到每场对局的摘要（宝可梦、难度、招式、道具、到达的分钟数与等级，以及结束方式）、你打开了哪些菜单画面，以及游戏发生错误时的错误消息与进行中对局的重播（其种子与你的输入，不含个人数据）。这些全都与 ph_ps 中的随机 ID 绑定，若你已登录，也会与你的账号 ID 及用户名绑定，但绝不会与你的电子邮件或姓名绑定。PostHog 在这里不使用 Cookie，也不会跨网站追踪你。

捐款是在 Stripe（stripe.com：信用卡、Apple Pay、Google Pay 与 Pix；较早的捐款也在 AbacatePay，abacatepay.com）的页面上付款。你的付款数据会直接交给他们，游戏永远看不到你的卡片数据。他们会告诉我们金额，以及（就像对任何收款方一样）付款人的数据（例如姓名与电子邮件），我们只用来记录这笔捐款。如果你提供了 @（或兑换了捐款的兑换码），它会与该游戏账号绑定，让奖励能送达；金额永远不会公开显示，只会显示赞助者徽章，而且你可以隐藏它。
